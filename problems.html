Lean 4.34.1 · Mathlib · one challenge file per problem

How to read this list. Every entry is a single Lean file whose main theorem is left as sorry. Open problems also come with their negation, so a system can settle them in either direction without the formulation giving away which side we expect.

Definitions that Mathlib does not yet offer live in a shared statement library that every system may use. Anything that would help to solve a problem stays out of reach.
